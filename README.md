# Жеке күнделік жүргізуге арналған веб-қосымша (Personal Diary)

## Жоба туралы
Бұл веб-қосымша пайдаланушыларға өздерінің күнделікті жазбаларын, ойлары мен көңіл-күй әсерлерін қауіпсіз түрде сақтауға, өңдеуге, сүзуге және экспорттауға мүмкіндік береді.

## Негізгі беттер тізімі
1. **Басты бет (`index.php`)** — жоба мүмкіндіктері мен жылдам өту сілтемелері.
2. **Тіркелу және кіру беті (`auth.php`, `logout.php`)** — пайдаланушыларды тіркеу, жүйеге кіргізу және сессияны аяқтау.
3. **Жеке кабинет / Күнделік (`diary.php`)** — жазбалар тізімі, жаңа жазба қосу, кілт сөздер мен көңіл-күй бойынша іздеу/сүзу және статистика.
4. **Жазбаны өңдеу (`edit.php`)** — сақталған жазбалардың мәтіні мен көңіл-күй санатын жаңарту.
5. **Жеке профиль (`profile.php`)** — пайдаланушы есімі мен құпиясөзін жаңарту.
6. **Экспорт (`export.php`)** — барлық күнделік жазбаларын `.txt` файлы түрінде жүктеп алу.

## Жоба құрылымы
```text
personal-diary-php/
├── config/
│   └── db.php              # MySQL дерекқорына PDO арқылы қосылу
├── css/
│   └── style.css           # Адаптивті стильдер кестесі
├── includes/
│   ├── header.php          # Ортақ жоғарғы навигация панелі
│   ├── footer.php          # Ортақ төменгі колонтитул
│   └── helpers.php         # Авторизация, CSRF және XSS қорғаныс функциялары
├── js/
│   └── script.js           # Клиенттік валидация және модальды терезе логикасы
├── auth.php                # Тіркелу және кіру логикасы
├── database.sql            # MySQL кестелер құрылымы мен бастапқы деректер
├── diary.php               # Негізгі күнделік беті (CREATE, READ, DELETE)
├── edit.php                # Жазбаны өңдеу беті (UPDATE)
├── export.php              # Жазбаларды .txt форматына экспорттау
├── index.php               # Басты бет
├── logout.php              # Сессияны жабу
├── profile.php             # Пайдаланушы профилі мен құпиясөзді өзгерту
└── README.md               # Жоба құжаттамасы
```

## Дерекқор құрылымы (ER-сызба)
- **`users`** кестесі (`id`, `username`, `email`, `password`, `created_at`) — тіркелген пайдаланушылар деректері.
- **`categories`** кестесі (`id`, `name`) — көңіл-күй санаттары.
- **`entries`** кестесі (`id`, `user_id`, `category_id`, `mood`, `title`, `content`, `created_at`) — пайдаланушылардың күнделік жазбалары (`FOREIGN KEY` арқылы байланысқан).

## Іске асырылған функционал және қауіпсіздік (PHP + MySQL/PDO)
- **Аутентификация:** `password_hash()`, `password_verify()` және `$_SESSION` арқылы қауіпсіз тіркелу, кіру және шығу (`auth.php`, `logout.php`).
- **Толық CRUD және аналитика:** Күнделік жазбаларын қосу, оқу, өңдеу (`edit.php`), өшіру (`diary.php`), `LEFT JOIN` сұраныстары және жазбалар статистикасы.
- **Ақпараттық қауіпсіздік:** SQL-инъекциядан қорғалған `PDO Prepared Statements` (`config/db.php`), XSS шабуылдарынан қорғау (`htmlspecialchars`) және формаларға арналған сессиялық `CSRF` токендері (`includes/helpers.php`).

## Жобаны локальды серверде іске қосу нұсқаулығы
1. Репозиторийді жүктеп алып, локальды сервердің (`XAMPP/htdocs` немесе `OpenServer/domains`) қалтасына орналастырыңыз.
2. `phpMyAdmin` панелін ашып, жоба түбіріндегі `database.sql` файлын импорттаңыз (`personal_diary` дерекқоры автоматты түрде құрылады).
3. Қажет болса, `config/db.php` файлындағы MySQL қосылу параметрлерін (`$host`, `$username`, `$password`) өз серверіңізге сәйкестендіріңіз.
4. Браузерде `http://localhost/personal-diary-php/index.php` мекенжайын ашып, тіркелу арқылы жұмысты бастаңыз.
